Ритм смен

Английское название: Shift Rhythm. Бесплатное приложение для Android.

Политика конфиденциальности Связь English

Ритм смен — бесплатное приложение для Android для тех, кто работает по сменам (например, сутки через двое или два через два). Оно помогает вести график смен, считать часы и оплату, хранить заметки и задачи.

Что умеет приложение

  • График смен: виды смен со своим временем и цветом, готовые циклы (2/2, 3/3, 5/2 и другие) и свой цикл.
  • Календарь с праздниками России, профессиональными и другими, которые выбирает пользователь.
  • Отчёт по сменам, часам и оплате за любой период с экспортом в PDF и Word.
  • Напоминания о начале смены, заметки, задачи, события из календарей телефона, виджеты на рабочий стол и прогноз погоды.

Вход через Google или Яндекс (по желанию)

Приложение работает без аккаунта. Если пользователь выбирает вход через Google, приложение использует API Google только для одного: хранить один файл ritm-smen.json с данными самого пользователя на его же Google Диске, чтобы данные были одинаковыми на всех его телефонах. Приложение открывает только файл, который создало само (разрешение drive.file). Из аккаунта берутся только фото профиля и адрес почты, чтобы показать, в какой аккаунт выполнен вход; они хранятся только на телефоне. API Google не используются для функций искусственного интеллекта.

English

Ритм смен (English name: Shift Rhythm) is a free Android app for people who work in shifts. It helps to keep a work schedule, to count hours and pay, and to keep notes and tasks: kinds of shifts with their own times, ready-made cycles (2/2, 3/3, 5/2 and others), a calendar of holidays, reports with export to PDF and Word, reminders, widgets and a weather forecast.

Optional sign-in with Google. The app works without an account. If the user signs in with Google, the app uses Google APIs for one purpose only: to keep a single file, ritm-smen.json, with the user's own schedule data in the user's own Google Drive, so that the data are the same on all the user's phones. The app can open only the file it created (the scope drive.file). It reads only the profile photo and the e-mail address of the account, to show which account is signed in, and keeps them only on the phone. The app does not use Google APIs for artificial-intelligence features.

The app has no servers of its own, no advertising and no analytics. Read the Privacy Policy. Contact: ritm-smen@googlegroups.com.
